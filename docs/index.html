KEMAMPUAN AUTOMASI

Dari tugas sederhana hingga pekerjaan kompleks.

Alih-alih hanya memberi instruksi, AI dapat bekerja lewat tool MCP pada komputer yang Anda hubungkan.

▤

Kelola berkas

Baca, tulis, cari, pindahkan, dan perbarui file langsung di direktori yang diizinkan.

⌘

Jalankan terminal

Jalankan perintah, inspeksi keluaran, dan bantu pekerjaan teknis pada mesin Anda.

◉

Pantau proses

Periksa program yang berjalan dan lihat proses atau sesi terminal melalui tool core.

⟲

Otomasi alur kerja

Rangkai langkah pekerjaan berulang menggunakan kemampuan AI dan tool yang tersedia.

⊞

Proyek dan kode

Telusuri struktur aplikasi, perbaiki kode, dan validasi hasil langsung di lingkungan kerja.

♙

Koneksi aman

Endpoint MCP memakai OAuth 2.0, PKCE, dan token sehingga operasi tidak terbuka bebas.

LANGKAH AWAL

Cukup tiga langkah untuk terhubung.

Dari komputer sendiri ke asisten AI yang Anda gunakan, lewat endpoint MCP yang sama.

01

Siapkan komputer

Jalankan engine dan gateway MCP pada komputer tujuan. Server host saat ini berada di sirobo.

02

Tambahkan konektor

Masukkan alamat MCP Otomasi pada ChatGPT atau aplikasi AI lain yang mendukung Remote MCP.

03

Berikan otorisasi

Setujui akses menggunakan kode pemilik melalui alur OAuth. Setelah terhubung, mulai bekerja lewat chat.

SATU PROTOKOL, BANYAK PILIHAN

Gunakan AI yang sudah Anda sukai.

Endpoint Remote MCP Otomasi dapat digunakan oleh klien yang mendukung Streamable HTTP dan alur OAuth yang kompatibel.
